# Security

Bürgerweg has no backend and no accounts. All learning data stays on the user's device, and the transfer code
travels only in the URL fragment (`#…`), which browsers never send to a server.

If you find a security or privacy problem (for example, a way a transfer link could leak data or run code), please
**don't open a public issue**. Contact the maintainers privately via the repository profile, and include steps
to reproduce it. We'll reply as soon as we can and credit you in the fix if you like.
